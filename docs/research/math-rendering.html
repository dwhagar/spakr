RES.2: Server-side LaTeX math

Research thread A, 2026-10-17. Unblocks RND.2; touches RND.4 (CSP), RND.5 (cache) and UI.14. Experiments on Ubuntu 24.04.5 with Chromium 141 (Playwright) for the browser checks.

Recommendation (decided: no Node.js anywhere)

The owner decided the product uses no Node.js at all, so maths renders in pure Python. The Temml option measured below was not taken.

  • Render LaTeX to MathML with latex2mathml (MIT, 3.81.1 from PyPI, pure Python, in-process, about 0.3 ms per formula). The output is MathML with no fonts, scripts or inline styles, so it fits the strict CSP and inherits text colour (dark mode works with no extra work).
  • Guards are mandatory because latex2mathml does not report errors. Before rendering, rewrite aligned and align to array{rl}. After rendering, reject the formula if the output contains an unknown command (<mi>\), a raw ampersand token, href or javascript, or if the converter raised (including RecursionError). A rejected formula is shown as escaped TeX source in <code class="math-error"> and logged. Limit: 2,000 characters per formula.
  • Coverage: fractions, roots, sums and integrals with limits, binomials, \operatorname, \mathbb, vectors, cases, matrices and aligned (after the rewrite) render. \ce (chemistry), unknown commands and \href fall back to TeX source. The editor guide (DOC.4) lists what is supported.
  • The renderer's output is trusted markup inserted after sanitising, never author HTML: author text only reaches latex2mathml as a TeX string. Each formula is hidden behind an inert token while Markdown runs and swapped in afterwards. Prototype: docs/research/poc/math_poc.py and render_poc.py.
  • If a better pure-Python renderer that reports errors appears, it replaces latex2mathml behind the same function; only RND.2 changes.

A 14-formula coverage test (aligned, cases, blackboard bold, \operatorname, binomials, nth roots, vectors, overlines, \text mixed with maths, calligraphic, \dfrac, norms, a damage formula) rendered without error in KaTeX and Temml; the only failure was \ce{H2O} in KaTeX (needs an extension there, supported by Temml).

Security checks

  • With trust false, Temml and KaTeX never emit an href for \href{javascript:alert(1)}{x}: both print the command name in an error colour and the arguments as plain math symbols (the error colour is an inline style, stripped server-side). \includegraphics gave an error element in Temml.
  • A recursive macro (\def\a{\a\a}\a) returned an error in KaTeX and Temml thanks to maxExpand; latex2mathml stopped with a RecursionError at depth 100.
  • Browser test (Chromium 141) with script-src 'self'; style-src 'self': Temml's MathML rendered correctly in light and dark colour schemes, display math stayed display:block from the CSS class although the style attribute was refused, and matrices only lost their small cell padding. Add mtd { padding: 0 .4em } to the shipped CSS and strip the style attributes server-side (the prototype does) so the console stays free of CSP violations.
  • The renderer runs on the worker or in the web process with a timeout (the prototype uses 10 s) and a size cap on the input (suggested: 2,000 characters per formula, 200 formulas per page).

Browser support

MathML Core renders natively in current Chrome and Edge (109 and newer), Firefox and Safari; that is stated from general knowledge and from the Chromium 141 run here, not from a compatibility database (the sites hosting one were not reachable from this session). Older browsers show the plain text content of the formula. Because this is a game database and not a mathematics site, that is acceptable; the editor guide (DOC.4) mentions it.

Pipeline and cost

Parse Markdown, sanitise, then replace tokens with MathML (see RES.1 and RES.3). Rendering 20 formulas in-process costs a few milliseconds, paid only on a cache miss: pages are cached by revision (caching), so each revision pays once, and previews (RND.6) cost the same. Prototype files: docs/research/poc/math_poc.py and render_poc.py.

Decision (made by the owner)

No Node.js anywhere in the product, including maths. Maths renders in pure Python with latex2mathml behind the guards above; unsupported commands show the TeX source.

What could not be verified

  • MathML browser support tables (hosts blocked); Safari behaviour was not tested.
  • LaTeX coverage beyond the formulas tried here; the editor guide should list supported constructs once real content exists.
