Deployment

Packages (Ubuntu LTS)

apt install apache2 libapache2-mod-wsgi-py3 mysql-server redis-server \
            git python3 python3-venv nodejs \\
            ffmpeg imagemagick libmagic1

Enable modules: a2enmod wsgi cgid headers rewrite. nodejs is used only to render maths (optional; formulas show as TeX source without it). MySQL needs innodb_ft_min_token_size=2 and innodb_ft_enable_stopword=OFF in mysqld.cnf for search to find short terms such as HP or Mi-Go (RES.7).

Services

  • apache2: serves the WSGI app and CGI scripts.
  • mysql: database spakr with a dedicated user.
  • redis-server: bound to localhost, password set.
  • spakr-worker.service: queue consumer (example unit in examples/).

Examples to be provided in examples/

  • spakr.conf.example: Apache virtual host (WSGI daemon mode, CGI directory, security headers, upload size limit, HTTPS with the operator's own valid certificate). A draft is included in this repository.
  • spakr-worker.service.example: systemd unit for the worker.
  • config.json.example: application configuration (the real config.json is git-ignored).

Plan for storage: uploaded originals and processed media live in a data directory outside the web root. Set Apache LimitRequestBody to at least 100 MB (the example vhost uses 10 MB; raise it for the upload route only).

Planned extra setup: MySQL credentials and the secret key in config.json (SMTP relay credentials can be entered in the admin settings afterwards); cache and media directories owned by the app user; an https contact URL for the User-Agent string.
