Components spakr needs to be operational

First pass, written by the TODO thread. spakr is a specialised wiki with WordPress-style static pages and database item pages (typed fields forming an infobox with an image, with the page text kept separate). Security is the first concern: where security and efficiency conflict, security wins, so the security components come first. Every component below is mapped to the TODO items that deliver it; the status column says whether the plan already covered it or whether this review found a gap that is now planned. A research thread is producing a fuller component catalogue; this page will be aligned with it when it lands.

49 components: 34 covered, 1 partly covered, 14 gaps found and now planned (new items are in the SEC category and the extra GIT, ENT, OPS and DOC items). Item links go to the dependency tree; the title shows the phase.
