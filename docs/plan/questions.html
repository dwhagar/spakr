Open questions and defaults chosen

Where the brief left a choice open, a default was picked so planning could continue. The six main questions have been answered (below).

Defaults chosen

TopicDefault
FrameworkPlain WSGI with a thin router and Jinja2 templates; no large framework
Queue libraryRQ on Redis
Content storageMarkdown in git is the source of truth; MySQL is a rebuildable index plus accounts
MathServer-side rendering to static markup; no client script
ReadingAnonymous readers allowed; editing needs an account
RegistrationAdmin creates accounts or approves sign-ups
Default HTML allowlistEmpty until the admin approves tags; suggested first approvals: sup, sub, u, abbr
Default upload typesPNG, JPEG, GIF, WebP, MP4/WebM/MOV video, common audio, TXT, MD, CSV; SVG and PDF off
VideoVideo and audio allowed by default, always transcoded by ffmpeg; shown with native HTML5 players, thumbnails from metadata or a video frame, audio cover art when present
Media embeddingMarkdown-level media: syntax expanded by the renderer into admin-controlled player markup; authors write no HTML
Media library callssubprocess for ffmpeg and ImageMagick (not Wand or ffmpeg-python); Pillow for in-process checks
Upload size limit10 MB for general files and images; 100 MB for video; both admin adjustable
PythonDistribution Python 3 on each LTS
