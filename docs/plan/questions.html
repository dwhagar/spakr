Open questions and defaults chosen

Where the brief left a choice open, a default was picked so planning could continue. The six main questions have been answered (below).

Defaults chosen

TopicDefault
FrameworkFlask (user decision) for the API and UI; the earlier plain-WSGI default is withdrawn
UI and APIDecided: the UI is first-party JavaScript calling /api/v1 over HTTP, same origin; public reading pages are also server-rendered for SEO and no-JS use
Sign-upDecided: invitation only
GM-onlyDecided: single flag in 1.0, with a reserved visibility-group column
ORM and migrationsSQLAlchemy and Alembic
Rolesreader, editor, GM, mod, admin; permission-based and editable by admins
Key limitsNon-admin users: up to 10 active API keys, admin adjustable; admins unlimited
Token lifetimesInvitation 7 days, password reset 1 hour
Media ladderWidths 1920, 1280, 640, 320 plus full, thumb, poster, cover; admin adjustable
Email transportSMTP through the local MTA or a configured relay
User-Agentspakr/<version> spakr-api/<n> (+<site contact URL>)
Queue libraryRQ on Redis
Content storageMarkdown in git is the source of truth; MySQL is a rebuildable index plus accounts
MathServer-side rendering to static markup; no client script
ReadingAnonymous readers allowed; editing needs an account
RegistrationAdmin creates accounts or approves sign-ups
Default HTML allowlistEmpty until the admin approves tags; suggested first approvals: sup, sub, u, abbr
Default upload typesPNG, JPEG, GIF, WebP, MP4/WebM/MOV video, common audio, TXT, MD, CSV; SVG and PDF off
VideoVideo and audio allowed by default, always transcoded by ffmpeg; shown with native HTML5 players, thumbnails from metadata or a video frame, audio cover art when present
Media embeddingMarkdown-level media: syntax expanded by the renderer into admin-controlled player markup; authors write no HTML
Media library callssubprocess for ffmpeg and ImageMagick (not Wand or ffmpeg-python); Pillow for in-process checks
Upload size limit10 MB for general files and images; 100 MB for video; both admin adjustable
Relation typesDecided: fixed vocabulary in an admin-managed relation_kind table, not free-form labels
Version stampMAJOR.MINOR in VERSION by hand; BUILD derived from git by scripts/version.sh (commits on main since VERSION last changed), so no CI is needed
SearchOne page_search index serves full-page content search and field filters (type, setting, tag, name, type fields); see database design
PythonDistribution Python 3 on each LTS
