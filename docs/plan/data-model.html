Data model

Every page has a common header (id, slug, type, title, setting tags, summary, created/updated, current git commit) and a Markdown body stored in git. Type-specific fields are stored in the database and mirrored in the page's front matter (MultiMarkdown metadata) so the git copy is self-describing.

Settings

Each page carries one or more setting tags: high fantasy modern / cosmic horror science fiction. Settings are data, so admins can add more later.

Relations

  • Typed links between pages stored in a relation table (from, to, kind, note), for example character member of nation-state, race grants special ability, item requires skill.
  • Plain wiki links in the Markdown body are parsed into untyped backlinks.
  • Places form a tree through parent_id.
